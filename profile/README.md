## Overview
As a locus map app aimed at people who spend time outdoors, Locus Map for Windows combines offline maps, route planning, and GPS tracking in one place. Preparing a trip usually starts with downloading the map area you'll need, after which routes can be sketched, waypoints saved, and the whole plan carried with you even where there's no signal. It's built to support the full cycle of a trip: planning it, navigating it, and looking back at it afterward.

## Features
**Offline maps.** Download map data in advance so navigation keeps working without a connection. **Route planning.** Sketch and adjust a route before you set out, using Locus Map as a locus map route planner for hikes, rides, or drives. **Track recording.** Log your actual path as you move so you can review it later. **Points of interest.** Save trailheads, campsites, and landmarks for future trips. **File import and export.** Move routes and tracks between Locus Map and other tools.
